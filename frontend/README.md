# Quiz App frontend

React and Vite UI for the Quiz App. Setup, the API, and the grading system are documented from the repository root:

- [Readme.md](../Readme.md)
- [Installation](../docs/EN_INSTALL.md)

From this directory: `npm ci`, then `npm run dev`, `npm test`, or `npm run lint`. Production assets are built inside the web Docker image, not committed here.
